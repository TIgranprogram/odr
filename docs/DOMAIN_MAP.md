# DOMAIN MAP (Карта доменов и связей)

> Эта карта связывает бизнес-сущности с техническими модулями и страницами UI.
> Используй её, чтобы не потерять связь между "запросом пользователя" и "кодом".

| Бизнес-домен | Backend Модуль | Frontend Маршрут | Страница / Экран | Ключевые связи |
|--------------|----------------|-------------------|-------------------|-------------------|
| **Пользователи** | `auth`, `users` | `/login`, `/admin/users` | Вход, Управление пользователями | Роли, Права, JWT |
| **Справочники** | `dictionaries` | `/dictionaries` | Справочники (Категории, Поставщики, и т.д.) | Используются во всех формах |
| **Снабжение** | `requisitions` | `/requisitions` | Панель Снабжения (Заявки) | Ссылки на Счета, Заказы |
| **Счета** | `invoices` | `/invoices` | Реестр счетов | Позиции из Заявок, Поставщики |
| **Заказы** | `orders` | `/orders` | Заказы (Спецификации) | Ссылки на Заявки |
| **Склад** | `warehouse` | `/warehouse` | Складской учет | Списание по пунктам заказов |
| **Аналитика** | `reports` | `/reports/odr` | Отчет ОДР | Агрегация Счетов и Категорий |

## Правила связей (Consistency)
1. **Tenant Isolation**: Все записи (кроме системных) всегда привязаны к `organizationId`.
2. **Snapshotting**: Переходы из Заявки в Счет должны сохранять неизменяемый "снимок" цен и объемов.
3. **IDOR**: Запрещено доступ к любой записи другого организации через прямые ID в URL.
