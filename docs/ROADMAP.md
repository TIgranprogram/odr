# ROADMAP (Дорожная карта проекта)

## 🗺️ Общая концепция
Создание надежной системы автоматизации снабжения, учета счетов и аналитики ОДР.

## 🏗️ Этап 1: Инфраструктура и Core (База)
- [ ] **Инициализация проекта:**
    - [ ] Структура папок `/backend` и `/frontend`.
    - [ ] Настройка Docker Compose (MongoDB, Node, Angular).
    - [ ] Настройка линтеров и конфигов (TSConfig, ESLint, Tailwind).
- [ ] **База данных и модели:**
    - [ ] Развертывание MongoDB и настройка Connection Factory.
    - [ ] Создание моделей: `User`, `Dictionary`, `Status`, `Priority`.
    - [ ] Скрипт `seed.ts` для первичной инициализации данных.
- [ ] **Авторизация (Auth):**
    - [ ] JWT сервис (Access/Refresh tokens).
    - [ ] AuthMiddleware и Guards.
    - [ ] Форма входа (Frontend) и API регистрации/логина.
- [ ] **Справочники (Dictionaries):**
    - [ ] API и интерфейсы для категорий, поставщиков, объектов.
- [ ] **UI Kit:**
    - [ ] Базовая верстка (Layout, Header, Sidebar).
    - [ ] Интеграция Angular Material / PrimeNG.

## 📦 Этап 2: Панель Снабжения (Заявки)
- [ ] **Справочники номенклатуры:**
    - [ ] Управление товарами/услугами.
- [ ] **Заявки (Requisitions):**
    - [ ] Таблица заявок с фильтрами.
    - [ ] Форма создания заявки (динамические поля из справочников).
    - [ ] Логика изменения статусов.
- [ ] **Связи с отчетами:**
    - [ ] Предварительная интеграция с логикой заказов (задел).

## 💰 Этап 3: Финансы и ОДР
- [ ] **Реестр счетов (Invoices):**
    - [ ] Создание счетов на основе заявок.
    - [ ] Привязка позиций к счетам.
- [ ] **Отчет ОДР:**
    - [ ] Агрегация данных по категориям и объектам.
    - [ ] Сводная таблица затрат.
- [ ] **Аналитика:**
    - [ ] Фильтры по датам, суммам, поставщикам.

## 🏭 Этап 4: Склад и Заказы (Задел)
- [ ] **Заказы (Orders):**
    - [ ] Спецификации заказов.
    - [ ] Привязка заявок к пунктам заказов.
- [ ] **Складской учет:**
    - [ ] Движение товара (Приход/Списание).
    - [ ] Списание по пунктам заказов.

## 🛠️ Технический долг и полировка
- [ ] Unit-тесты ключевых сервисов.
- [ ] Документация API (Swagger).
- [ ] Оптимизация производительности MongoDB запросов.
