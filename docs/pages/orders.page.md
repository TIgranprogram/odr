# Страница: Заказы

- **Маршрут:** `/orders` · **Компонент:** `frontend/src/app/features/orders/orders.component.ts`
- **Доступ:** JWT.

## Назначение
Просмотр и создание заказов со спецификацией (позиции с количеством, единицей,
ценой и суммой).

## UI-действия
| Элемент | Действие | Результат |
|---|---|---|
| Кнопка «＋ Новый заказ» | click | модалка создания |
| Кнопка ✏️ (строка) | click | редактирование позиции/заказа |
| Кнопка 🗑️ (строка) | click | удаление (с подтверждением) |
| Поля шапки (номер, дата, заказчик, статус) | ввод | данные заказа |
| «＋ Добавить строку» | click | новая позиция спецификации |
| ✕ у строки | click | удаление позиции (нельзя удалить последнюю) |
| Кнопка «Сохранить» | submit | create/update заказа c `items` |
| «Отмена» / ✕ | click | закрытие модалки |

## API
| Метод | Путь | Когда |
|---|---|---|
| GET | `/api/orders` | загрузка списка |
| POST | `/api/orders` | создание |
| PUT | `/api/orders/{id}` | редактирование |
| DELETE | `/api/orders/{id}` | удаление |

## Уведомления и ошибки
- Успех — тост. `400` — «orderNumber is required…» и др. от серверной валидации.
- Ошибка выводится в тосте и в баннере страницы.

## Связи
- Позиции заказа: `{ itemTitle, quantity, unit, price, total }`.
- Задел на списание по пунктам заказов со склада (Этап 4, ROADMAP).
