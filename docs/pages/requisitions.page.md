# Страница: Панель снабжения — Заявки

- **Маршрут:** `/requisitions` · **Компонент:** `frontend/src/app/features/requisitions/requisitions.component.ts`
- **Доступ:** JWT (любая роль).

## Назначение
Создание, редактирование, удаление и поиск заявок на закупку с серверной
пагинацией и фильтрами. Основа для формирования счетов/заказов и ОДР.

## UI-действия
| Элемент | Действие | Результат |
|---|---|---|
| Кнопка «＋ Новая заявка» | click | модалка создания (пустая форма) |
| Поле «Поиск…» | ввод (debounce 300 мс) | фильтр `search`, страница → 1 |
| Селект «Все статусы» | выбор | фильтр `status`, страница → 1 |
| Селект «Все заказчики» | выбор | фильтр `customer`, страница → 1 |
| Кнопка ✏️ (строка) | click | модалка с заполненной формой → сохранение |
| Кнопка 🗑️ (строка) | click | подтверждение → удаление |
| «← Назад» / «Вперёд →» | click | переход по страницам (limit 25) |
| Поля формы (категория, наименование, кол-во, ед., поставщик, заказчик, компания, приоритет, цена с НДС, статус) | ввод | валидация обязательных |
| Кнопка «Сохранить» | submit | create или update |
| «Отмена» / ✕ / backdrop | click | закрытие модалки без сохранения |

## API
| Метод | Путь | Когда |
|---|---|---|
| GET | `/api/requisitions/paged?search&status&customer&page&limit` | загрузка/смена фильтров/страниц |
| POST | `/api/requisitions` | создание |
| PUT | `/api/requisitions/{id}` | редактирование |
| DELETE | `/api/requisitions/{id}` | удаление |
| GET | `/api/dictionaries` | заполнение селектов (Types/Units/Suppliers/Customers) |

## Уведомления и ошибки
- Успех: «Заявка создана/обновлена/удалена».
- `400` — ошибка валидации (текст с сервера), `403`/`401` — interceptor.
- Индикатор `loading` во время запроса.

## Связи
- Статусы/приоритеты — `core/constants.ts`.
- Учитываются в ОДР (`/api/odr`) при статусах `✅ Заказать / 💰 Оплачено / ☑️ Получено`.
