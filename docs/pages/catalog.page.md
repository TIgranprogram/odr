# Страница: Каталог продуктов

- **Маршрут:** `/catalog` · **Компонент:** `frontend/src/app/features/catalog/catalog.component.ts`
- **Доступ:** JWT.

## Назначение
Каталог продукции (импортируется из `products.csv`, 288 позиций): поиск по
наименованию/SKU/поставщику и фильтр по категории.

## UI-действия
| Элемент | Действие | Результат |
|---|---|---|
| Поле «Поиск по названию, SKU, бренду…» | ввод | фильтр `search` |
| Селект категории | выбор | фильтр `category` |
| Сброс фильтров | click | показать все |

## API
| Метод | Путь | Когда |
|---|---|---|
| GET | `/api/products?search&category` | загрузка и фильтрация |
| GET | `/api/products/sku/{sku}` | (сервис) поиск по внутреннему SKU |
| POST | `/api/products` | (сервис) добавление продукта |

## Уведомления и ошибки
- Пустой результат — сообщение «Ничего не найдено».
- `409` при создании дублирующего `internalSku`.

## Связи
- Источник данных — `данные для заполнения на сайте/data/db_spotninyg - products.csv`.
