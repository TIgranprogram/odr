# Страница: Справочники

- **Маршрут:** `/dictionaries` · **Компонент:** `frontend/src/app/features/dictionaries/dictionaries.component.ts`
- **Доступ:** JWT (изменение доступно всем авторизованным; при необходимости — ограничить ADMIN).

## Назначение
Управление справочными значениями по категориям: `Types`, `Units`, `Suppliers`,
`Customers` (используются в формах заявок/счетов).

## UI-действия
| Элемент | Действие | Результат |
|---|---|---|
| Селект категории | выбор | фильтр списка по `category` |
| Кнопка ✏️ (строка) | click | загрузка значения в форму (`startEdit`) |
| Кнопка 🗑️ (строка) | click | удаление записи |
| Поля (категория, значение) | ввод | данные записи |
| Кнопка «Сохранить/Добавить» | submit | create/update |
| «Отмена» | click | сброс формы (`resetForm`) |

## API
| Метод | Путь | Когда |
|---|---|---|
| GET | `/api/dictionaries` | все записи |
| GET | `/api/dictionaries/{category}` | записи категории |
| POST | `/api/dictionaries` | создание |
| PUT | `/api/dictionaries/{id}` | изменение |
| DELETE | `/api/dictionaries/{id}` | удаление |

## Уведомления и ошибки
- Тосты success/error; `400` — валидация.

## Связи
- Метки категорий — `DICTIONARY_LABELS` в `core/constants.ts`.
- Seed наполняет справочники из CSV (категории объединяются в `Types`).
