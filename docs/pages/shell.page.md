# Страница: Оболочка приложения (Shell / Layout)

- **Маршрут:** контейнер для вложенных маршрутов (`shell.routes.ts`)
- **Компонент:** `frontend/src/app/features/shell/shell.component.ts`
- **Доступ:** `authGuard` (весь shell защищён).

## Назначение
Каркас UI: боковое меню (навигация), заголовок, область `router-outlet` и хост
уведомлений. Служит обёрткой всех рабочих экранов.

## UI-действия
| Элемент | Действие | Результат |
|---|---|---|
| Пункт меню «Заявки» | click | переход `/requisitions` |
| Пункт меню «Каталог» | click | переход `/catalog` |
| Пункт меню «Заказы» | click | переход `/orders` |
| Пункт меню «Счета» | click | переход `/invoices` |
| Пункт меню «Склад» | click | переход `/warehouse` |
| Пункт меню «Справочники» | click | переход `/dictionaries` |
| Пункт меню «ОДР» | click | переход `/reports/odr` |
| Кнопка «Выйти» | click | `AuthService.logout()` — очистка токенов → `/login` |
| Тосты | автозакрытие / клик ✕ | скрытие уведомления |

## API
Нет прямых запросов (кроме logout-очистки локального состояния).

## Уведомления и ошибки
- `ToastComponent` (`shell/toast.component.ts`) показывает success/error/info.
- `authInterceptor`: `401` → попытка refresh → при неудаче «Сессия истекла» и выход;
  `403` → «Доступ запрещён».
- Пустой путь `''` и неизвестные пути редиректят на `requisitions`.

## Связи
- Навигация соответствует файлам `docs/pages/*` для каждого экрана.
