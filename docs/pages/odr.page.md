# Страница: Отчёт ОДР

- **Маршрут:** `/reports/odr` · **Компонент:** `frontend/src/app/features/reports/odr.component.ts`
- **Доступ:** JWT.

## Назначение
Финансовый результат (доходы/расходы/чистая прибыль) за период + управление
«Прочими поступлениями» (доходы, не связанные со счётом). Правила расчёта —
`docs/ODR_LOGIC.md`.

## UI-действия
| Элемент | Действие | Результат |
|---|---|---|
| Поля «Дата с / по» | изменение | `GET /api/odr?start&end` |
| Кнопки «Текущий месяц / Квартал / Год» | click | быстрый выбор периода + перезапрос |
| Кнопка ✏️ (поступление) | click | загрузка в форму (`startEditIncome`) |
| Кнопка 🗑️ (поступление) | click | удаление (с подтверждением) |
| Поля формы поступления (дата, категория, сумма, примечание) | ввод | данные |
| Кнопка «Добавить/Обновить» | submit | create/update поступления |
| «Отмена» | click | сброс формы (`resetIncomeForm`) |

## API
| Метод | Путь | Когда |
|---|---|---|
| GET | `/api/odr?start&end` | загрузка/смена периода |
| GET | `/api/additional-incomes` | список прочих поступлений |
| POST | `/api/additional-incomes` | добавление |
| PUT | `/api/additional-incomes/{id}` | изменение |
| DELETE | `/api/additional-incomes/{id}` | удаление |

## Уведомления и ошибки
- Тосты success/error; сумма поступлений входит в «Доходы» за период.
- Категории поступлений — `INCOME_CATEGORIES` (`core/constants.ts`).

## Связи
- Расход считается по заявкам в статусах `✅ Заказать / 💰 Оплачено / ☑️ Получено`
  как `priceWithVat × quantity`, без двойного учёта по `invoiceRef` (T-1.1).
