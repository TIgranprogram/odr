# Страница: Склад

- **Маршрут:** `/warehouse` · **Компонент:** `frontend/src/app/features/warehouse/warehouse.component.ts`
- **Доступ:** JWT.

## Назначение
Просмотр складских остатков и журнала движений (приход/списание); регистрация
новых движений.

## UI-действия
| Элемент | Действие | Результат |
|---|---|---|
| Поле «Поиск по наименованию…» | ввод | клиентский фильтр остатков |
| Кнопка «+ Движение» | click | модалка нового движения |
| Поля формы (тип, дата, наименование, кол-во, ед., примечание) | ввод | данные движения |
| «Сохранить» / «Отмена» | click | `POST /api/warehouse` / закрытие |
| ✏️ / 🗑️ (строка) | click | правка/удаление движения |

## API
| Метод | Путь | Когда |
|---|---|---|
| GET | `/api/stockitems` | остатки |
| GET | `/api/warehouse` | журнал движений |
| POST | `/api/warehouse` | новое движение |
| PUT | `/api/warehouse/{id}` | изменение |
| DELETE | `/api/warehouse/{id}` | удаление |

## Уведомления и ошибки
- Тип движения: `INCOME` (приход) / `OUTCOME` (списание) — валидируется на бэкенде
  (`"type" is required…`), при ошибке `400` + тост.

## Связи
- Движения формируют складской учёт; в перспективе — авто-списание по заказам.
