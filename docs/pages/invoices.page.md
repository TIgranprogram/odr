# Страница: Счета (Invoices)

- **Маршрут:** `/invoices` · **Компонент:** `frontend/src/app/features/invoices/invoices.component.ts`
- **Доступ:** JWT.

## Назначение
Реестр счетов поставщиков; создание счёта с позициями (позиция → количество,
цена, сумма), привязка к заявкам.

## UI-действия
| Элемент | Действие | Результат |
|---|---|---|
| Кнопка «+ Новый счёт» | click | модалка создания |
| ✏️ / 🗑️ (строка) | click | редактирование / удаление |
| Поля (номер, дата, поставщик, статус, сумма) | ввод | данные счёта |
| Поля строки (наименование, кол-во, цена) | ввод | расчёт суммы позиции |
| «+ Добавить строку» / ✕ | click | добавить/удалить позицию (мин. 1) |
| «Сохранить» / «Отмена» | click | сохранение/отмена |

## API
| Метод | Путь | Когда |
|---|---|---|
| GET | `/api/invoices` | список |
| POST | `/api/invoices` | создание |
| PUT | `/api/invoices/{id}` | редактирование |
| DELETE | `/api/invoices/{id}` | удаление |

## Уведомления и ошибки
- Тосты success/error; `400` — валидация; `401/403` — interceptor.

## Связи
- Счёт может ссылаться на заявку (`invoiceRef`) — исключает двойной учёт в ОДР.
