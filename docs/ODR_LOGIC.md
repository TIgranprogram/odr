# ОДР Logic — Правила расчета Доходов и Расходов

> Этот документ фиксирует бизнес-логику формирования отчета ОДР.

## 💰 Доходы (Income)
Доходы в отчете считаются на основе сущности **Счет (Invoice)**.
- **Критерий включения**: Статус счета = `Оплачено`.
- **Сумма**: `totalAmount` из счета.
- **Категории**: Определяются на основе типа счета или привязанных к нему позиций.
- **Дополнительные поступления**: В системе предусмотрена возможность ручного ввода «Прочих поступлений» (не связанных со счетом), которые будут попадать в ОДР с ручным выбором категории.

## 💸 Расходы (Expenses)
Расходы в отчете формируются на основе **Заявок на снабжение (Requisition)** и **Заказов (Order)**.
- **Критерий включения**: Заявка/Заказ находится в статусе «Заказано», «Получено» или «Оплачено».
- **Сумма**: `priceWithVat` (Цена с НДС) из позиции заявки или общая сумма из заказа.
- **Связка**: Если заявка привязана к счету, расчет расхода идет по сумме счета (чтобы избежать двойного счета, если счет покрывает несколько заявок).

## 📦 Склад (Warehouse)
- Склад используется для учета текущих остатков ТМЦ.
- Списание со склада (Outcome) фиксируется в движении, но **не является** первичным методом расчета расхода в текущей версии системы (расход фиксируется в момент оплаты/заказа).

## 📊 Визуализация
- Группировка в ОДР: по датам (день/месяц), по категориям (Оборудование, Метизы и т.д.) и по заказчикам.
- Цветовая индикация: Доходы — зеленый, Расходы — красный.
